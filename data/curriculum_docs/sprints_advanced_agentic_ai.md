# Sprints Advanced Agentic AI Bootcamp

## Module 1 - Python Foundations
Python syntax, data types, variables, control flow, collections, iteration, exceptions and writing readable programs.

## Module 2 - Python Functions, Testing and Debugging
Functions, parameters, return values, modularity, unit tests, assertions, debugging workflows and validating Python assignments against expected outputs.

## Module 3 - LLM APIs and Prompt Engineering
Calling language-model APIs, system and user messages, prompt structure, context windows, temperature, token usage, prompt injection awareness and grounded generation.

## Module 4 - Structured Outputs with Pydantic
Pydantic models, typed fields, validation, field descriptions, JSON schemas, output parsing and rejecting malformed or out-of-range model responses.

## Module 5 - LangChain Chains and LCEL
Composable runnable components, prompt templates, model calls, output parsers, sequential composition, parallel branches and conditional routing with LCEL.

## Module 6 - Document Ingestion and Embeddings
Loading curriculum documents, parsing metadata, splitting text into overlapping chunks, generating embeddings, consistent embedding models and indexing source documents.

## Module 7 - Vector Stores and Retrieval-Augmented Generation
ChromaDB collections, similarity search, top-k retrieval, metadata filters, source citations, retrieval latency and grounding generated answers in retrieved passages.

## Module 8 - Tools and Function Calling
Defining typed tools, tool descriptions, argument validation, function calling, API/database integrations, structured tool results and graceful tool-failure handling.

## Module 9 - ReAct Agents
Reason-and-Act loops, selecting tools, reading observations, deciding next actions, limiting unsupported claims and grounding answers in tool output.

## Module 10 - SQL and Data Tools
Relational schemas, SELECT queries, filtering, joins, aggregation, parameterized queries, read-only database access and interpreting structured learner records.

## Module 11 - LangGraph State Machines
Typed graph state, nodes, edges, conditional routing, orchestrator-worker architectures, graph compilation, execution and state transitions.

## Module 12 - Memory and Checkpointing
Conversation state, checkpoints, thread identifiers, persistent sessions, learner-scoped memory, state recovery and isolation between independent learners.

## Module 13 - Evaluator-Optimizer and Reflection Patterns
Evaluation criteria, executable checks, feedback loops, bounded refinement, quality measurement, latency budgets and stopping conditions.

## Module 14 - Human-in-the-Loop and Safety
Approval interrupts, human review, secure code execution, sandbox isolation, least privilege, fail-closed behavior, auditability and safe handling of unverifiable facts.

## Module 15 - Capstone and Career Readiness
Learner progress, career-readiness evidence, placement criteria, employer preferences, salary expectations in EGP, deterministic job matching and human-approved placement proposals.
